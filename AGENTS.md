# Agents

`CLAUDE.md` is the instruction file for every coding agent in this repo. Read it first.

Per-area rules are in `.claude/rules/` (`web.md`, `api.md`, `db.md`, `shared.md`). Claude Code loads them automatically; other agents should read the one for the area they're changing.

Scope, plan, and tasks are in Linear (link in `CLAUDE.md`). Nothing here overrides `CLAUDE.md`.
